Overview
Understanding the two models in DeepSeek's V4 family
Key fact: DeepSeek does not offer a "Free" tier natively. The two production models are V4 Flash (economical, fast) and V4 Pro (flagship, maximum capability). A free Flash variant exists only as a limited-time promotion on the OpenCode Zen platform.

DeepSeek V4 was officially released on April 24, 2026 as an open-source model family. Both models share the same architecture — Mixture of Experts (MoE) — but differ dramatically in scale, performance, and cost. Both are distributed under the permissive MIT license with open weights available on Hugging Face.

This guide covers everything you need to choose the right model: technical specifications, pricing across DeepSeek API and OpenCode Go, benchmark performance, and practical recommendations.

When to Use Each Model
Practical decision guide based on task type

Choose V4 Flash when…

The economical workhorse
  • You need speed and high throughput
  • Running batch processing or automation
  • Working on routine coding tasks
  • Budget is a primary concern
  • You have simple, well-defined queries
  • Generating drafts or initial content
  • Running many parallel requests (2,500 concurrency)
  • Testing and development workflows

Choose V4 Pro when…

The flagship for complex work
  • You need deep factual knowledge
  • Tackling complex, multi-step reasoning
  • Working in specialized domains (law, medicine, science)
  • Writing production-grade code with edge cases
  • Research tasks requiring broad world knowledge
  • Quality matters more than speed or cost
  • You're working as an executive agent (like Pandu)
  • Complex debugging and architecture decisions
